# StudyQuest Pro 📚

StudyQuest Pro is a web-based study management platform developed using Django. It helps students organize their learning journey by managing subjects, study materials, tasks, and progress in a simple and user-friendly interface.

---

## 🚀 Features

- User Registration and Login
- Dashboard for Students
- Subject Management
- Study Material Management
- Task and Assignment Tracking
- Progress Monitoring
- Secure Authentication System
- Responsive User Interface
- Admin Panel for Management

---

## 🛠️ Technologies Used

- Python 3.x
- Django 5.x
- HTML5
- CSS3
- Bootstrap
- SQLite3
- JavaScript
